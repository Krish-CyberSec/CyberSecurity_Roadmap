# Labs: MAC Addresses

## Lab 1

### Objective

Learn how to identify network adapters and their corresponding MAC addresses using Windows Command Prompt.

### Steps

1. Open **Command Prompt**.
2. Run the following command:

```cmd
ipconfig /all
```

### Questions & Answers

#### 1. How many network adapters does your computer have?

**Answer:** `5 network adapters`

---

### Steps

1. Run the following command:

```cmd
getmac
```

2. Compare the output with the information from `ipconfig /all`.
