# Labs: IP Addresses

## Lab 1

### Objective
Find your computer's IP address using the Command Prompt and identify whether it is a private or public IP address.

### Steps

1. Open **Command Prompt**.
2. Run the following command:

```cmd
ipconfig
```

### Questions & Answers

#### 1. What is your IPv4 address?

**Answer:** `10.18.8.14`

#### 2. Is it private or public? Why?

**Answer:** It is a **private IP address** because it belongs to the **10.0.0.0/8** private IP address range reserved by RFC 1918. Private IP addresses are used within local networks (such as homes, schools, and offices) and cannot be accessed directly from the public internet.
